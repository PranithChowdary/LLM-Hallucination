## Read this before quoting a number

- Labels are provisional NLI labels, not verified ground truth. Every detector number below inherits their errors.
- These are exploratory results on the calibration split, not held-out test performance.
- AUROC below 0.5 means the score points the wrong way for that label.
- Accuracy-probe layers were picked using these same labels, so those numbers are optimistic.
- B8 results come from one validation fold, so they aren't directly comparable with the cross-fitted or full-data results.
- Single-pass and sampling detectors differ in cost, which is not shown here.
